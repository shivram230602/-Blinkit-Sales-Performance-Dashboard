# -Blinkit-Sales-Performance-Dashboard
🔍 Project Overview

The dashboard provides a comprehensive overview of sales trends, outlet performance, product categories, and customer purchasing behavior. It is designed to help stakeholders quickly understand key business metrics and make data-driven decisions.

🎯 Objectives

To analyze overall sales performance across different outlet types and locations

To understand customer preference patterns based on product categories and item types

To compare outlet size and establishment year with sales outcomes

To identify high-performing and low-performing segments

📈 Key Insights & Features

Total Sales, Average Sales, and Item Count KPIs

Sales distribution by:

Outlet Type

Outlet Size

Outlet Location Tier

Product Category

Trend analysis based on Outlet Establishment Year

Interactive filters and slicers for dynamic exploration

Clear visualizations using bar charts, line charts, and donut charts

🛠 Tools & Technologies

Power BI – Data modeling, visualization, and dashboard creation

Data Cleaning & Transformation – Performed using Power Query

DAX – Used for calculated measures and KPIs

Integration with real-time or larger datasets
